# 测试原理与模型边界

## 暗态 I–V

关闭光源，在反向偏压范围扫描电压。当前模型由二极管饱和电流、并联电阻电流和高斯噪声构成。在参考偏压 `Vref=-2 V` 处取电流绝对值作为暗电流。实际测量还需考虑环境遮光、温度稳定、积分时间、线缆漏电和治具清洁。

## 光照 I–V 与响应度

打开 850 nm 虚拟光源，设定入射功率 `P`。同一偏压处以光照电流与暗电流之差作为光生电流：

`I_photo = |I_light - I_dark|`

响应度：`R = I_photo / P`，单位 A/W。真实系统中的 `P` 应为到达光敏面的经校准功率，而不只是光源面板设定值。

## 重复性

同一偏压、光功率下采样多次，以电流标准差和变异系数 `CV = s / mean` 描述短期重复性。CV 不是完整的不确定度预算，也不能代替带宽、噪声谱或长期稳定性分析。

## 噪声、NEP 与比探测率

在暗态参考偏压下重复采样，以样本标准差估计 RMS 噪声电流。配置测量带宽 `B` 后，等效噪声电流密度为 `i_n = i_rms / sqrt(B)`；噪声等效功率 `NEP = i_n / R`；比探测率 `D* = sqrt(A) / NEP`，其中 `A` 为有效面积。当前数值用于软件流程演示，不构成真实噪声谱或校准结果。

## 线性度、稳定性与光谱响应

线性度使用多个光功率点拟合光生电流，输出 R² 和相对满量程最大偏差。稳定性使用固定功率的模拟时间序列计算首尾漂移与相对极差。光谱响应在多个波长点计算响应度，提取峰值波长和目标波长相对峰值响应。真实测试必须使用经校准、可调谐的光源及功率计。

## 数据清洗与批次异常

进入参数计算前检查数值有效性并剔除非有限值及完全重复记录，同时保留原始点数、清洗后点数和剔除计数。批次异常检测对关键指标进行对数变换和中位数绝对偏差（MAD）稳健评分；异常标记用于复核，不替代规格 Pass/Fail。

## 三态判定

- PASS：测试有效完成且所有规格满足。
- FAIL：测量有效，但暗电流、响应度、重复性或 Compliance 超规。
- ERROR：通信或安全错误导致无法形成有效器件结论。

## 模型限制

当前为教学级简化模型，未包含结电容、频率响应、雪崩增益、温度漂移、光谱响应、仪器量程切换、积分时间与校准不确定度。因此它证明的是自动测试软件能力，不是器件真实性能。
