# 项目立项书

## 一、项目基本信息

- 项目名称：基于虚拟仪器的光电探测器自动化测试与质量分析平台
- 英文名称：Automated Photodetector Test and Quality Analysis Platform
- 项目类型：个人学习与求职作品 Demo
- 面向岗位：半导体测试开发、产品测试、设备应用、实验室自动化
- 第一阶段周期：14 天
- 第一阶段版本：v0.1.0（仿真验证版）

## 二、立项背景

人工测试光电二极管存在参数设置重复、记录易错、操作一致性不足、批次数据难追溯等问题。半导体测试工作不仅需要理解器件，还要求把仪器控制、测试流程、规格判定、异常分类和质量统计组成稳定系统。本项目以光电二极管为对象，建立一条可在无硬件环境复现、后续迁移到真实仪器的自动测试链路。

## 三、目标与非目标

目标：

1. 自动执行暗态/光照 I–V、响应度和重复性测试。
2. 明确区分器件 FAIL 与测试系统 ERROR。
3. 以 YAML 管理测试规格，以固定种子复现仿真。
4. 自动形成原始数据、结构化结果、数据库、日志和报告。
5. 通过统一接口预留 Keithley/Keysight 等 VISA/SCPI 仪器接入。
6. 形成可由第三方复现、审阅和提问的工程材料。

非目标：

- v0.1.0 不声称具有真实器件测量精度。
- 不覆盖生产级校准、治具补偿、ESD 认证、STDF 全流程或设备认证。
- 不以图形界面的复杂程度代替测试工程能力。

## 四、交付范围

- 分层 Python 源码、配置、单元/集成测试；
- 命令行 Demo 与 Streamlit 展示界面；
- 20 DUT 批量样例，包含不少于 7 种器件/系统状态；
- CSV、JSON、SQLite、日志、HTML 测试报告；
- 项目原理、架构、复现、验收、风险、审阅和贡献文档。

## 五、技术路线

配置层读取测试方案；仪器层向上提供统一测量接口；DUT 层生成带噪声和故障的简化物理响应；序列层执行测试；分析层提取参数并三态判定；存储/报告层形成追溯证据。虚拟 SMU 与 VISA SMU 实现相同接口，因此上层流程原则上无需重写。

## 六、验收指标

1. 一条命令完成 20 个 DUT 批量仿真。
2. 固定配置和随机种子可复现数值。
3. 样例同时出现 PASS、FAIL、ERROR。
4. 报告与数据库可追溯至 run_id、DUT 和配置。
5. 自动化测试覆盖模型、判定、安全互锁和端到端产物。
6. 仿真结果与未验证硬件部分均有清晰声明。

## 七、风险与控制

| 风险 | 影响 | 控制措施 |
|---|---|---|
| 将仿真当真实实验 | 结论失真 | 所有输出显著标注 SIMULATED DATA |
| 参数缺乏器件手册依据 | 阈值不具行业有效性 | 电脑端接入具体器件后按 datasheet 修订 |
| 通用 SCPI 不适配具体 SMU | 真机无法运行 | 按仪器编程手册建立型号驱动与硬件在环测试 |
| 随机噪声导致结果漂移 | 难复现 | 固定随机种子并保存配置快照 |
| UI 依赖阻塞核心流程 | 无法演示 | 提供轻依赖命令行入口 |

## 八、阶段门

- M1：仿真链路、三态判定和测试通过。
- M2：本人完成阈值修改、故障定位、回归测试及 Git 记录。
- M3：选定真实器件/仪器，完成 datasheet 参数映射和驱动验证。
- M4：加入校准、不确定度、温漂/线性度和生产数据格式。

## 九、立项结论

项目与光电信息专业和半导体测试岗位具有直接关联，第一阶段不依赖昂贵硬件，技术风险可控，输出可量化并可接受第三方审阅，同意按 v0.1.0 范围立项实施。
