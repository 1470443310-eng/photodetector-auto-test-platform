# 项目总体方案

## 1. 应用场景

对一批光电二极管执行标准化自动测试，减少人工设置、记录和判定误差，并支持结果追溯、批次统计与后续真实仪器接入。

## 2. 核心测试

1. 暗态 I-V：提取指定反向偏压下的暗电流。
2. 光照 I-V：测量光生电流与曲线特征。
3. 响应度：计算光生电流与入射光功率之比。
4. 重复性：计算多次采样的均值、标准差和变异系数。
5. 进阶项：线性度、过流保护、故障注入。

## 3. 系统流程

读取方案 → 连接仪器 → 安全检查 → 暗态测试 → 光照测试 → 参数提取 → PASS/FAIL/ERROR → 保存数据 → 生成报告。

## 4. 系统模块

- 仪器层：虚拟 SMU、虚拟光源、PyVISA 真实设备适配器。
- DUT 层：正常、漏电、低响应、噪声、非线性、开路、短路模型。
- 流程层：可配置测试步骤与重试策略。
- 判定层：规格判断及 PASS/FAIL/ERROR 分类。
- 数据层：CSV、JSON、SQLite；STDF 为进阶接口。
- 展示层：Streamlit 与 Plotly。
- 验证层：pytest 单元、集成和端到端测试。

## 5. 三种状态

- PASS：测试有效完成，全部指标满足规格。
- FAIL：测试有效完成，但器件指标超出规格。
- ERROR：因通信、超时、配置或系统异常无法形成有效结论。

## 6. 开源参考

- google/openhtf：硬件测试流程抽象参考。
- pyvisa/pyvisa：VISA 仪器通信。
- pyvisa/pyvisa-sim：无硬件通信仿真。
- pymeasure/pymeasure：测量流程和界面参考。
- Semi-ATE/STDF：半导体测试数据格式进阶参考。
