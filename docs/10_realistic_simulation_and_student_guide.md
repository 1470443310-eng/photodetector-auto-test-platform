# 现实量级仿真与学生读数指南

## 两种数据模式

- **现实波动模式（网页默认）**：每次运行生成新的批次种子，模拟同一型号器件的制造离散、实验室温度变化、仪器增益误差、零点偏移和噪声底。不同批次数据应不同。
- **教学复现模式**：使用配置文件中的固定种子。相同代码和配置应得到相同结果，用于调试、阈值实验和自动化回归。

每份 JSON、SQLite 和 HTML 报告均保存有效种子、模式、温度和模拟误差参数。现实波动不等于不可复现；只要保留种子即可追溯。

## 现实依据

当前参考对象是通用硅 PIN 光电二极管，而不是宣称仿真某一具体料号。数量级参考：

- Vishay BPW34 数据手册：25°C、10 V反偏暗电流典型2 nA、最大30 nA；峰值波长约900 nm；光谱范围约430～1100 nm；NEP典型约 `4e-14 W/√Hz`。
- Hamamatsu《Si photodiodes》技术说明：噪声由并联电阻热噪声、暗电流散粒噪声和光电流散粒噪声组成；`NEP = 噪声电流密度 / 响应度`；`D* = sqrt(面积) / NEP`。
- Keithley 低电流测量资料：低电流结果会受到屏蔽、线缆/治具漏电、等待时间、量程和环境噪声影响。

项目默认参考面积为 `0.075 cm²`、目标波长850 nm、入射光功率75 µW、25°C附近波动。规格是教学验收线，不是BPW34出厂规格替代品。

## 如何读判定

- **通过（PASS）**：测试有效，所有配置规格均满足。
- **不合格（FAIL）**：测试有效，但至少一个指标越限；应查看失败原因和建议复测项。
- **测试异常（ERROR）**：通信或安全问题导致没有形成有效器件结论，不能把它算成器件坏。
- **批次异常**：器件相对同批统计离群，应优先复测；异常标记不替代规格判定。

## 常见指标直觉

- 暗电流、噪声、NEP：通常越小越好。
- 响应度：在规定波长、偏压和光功率下落入数据手册/测试规范范围才算合格，不是越高越好。
- D*：同类器件、相同口径下通常越大越好。
- 线性R²：越接近1越好；线性偏差越小越好。
- 重复性CV、稳定性漂移：越小表示测量越稳定。
- 光谱峰值：要与光源波长和应用匹配。

## 真实性边界

本模型让数据形态、数量级和误差来源更接近实际测试，但没有替代器件数据手册、校准光功率计、温控、低噪声治具或硬件在环验证。展示时必须称为“参考真实量级的教学仿真”。
